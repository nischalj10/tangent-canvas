# App icon provenance

The icon is the user's original **Minimalist Charcoal Branching Emblem**, downloaded from the image URL embedded in this public [ChatGPT share](https://chatgpt.com/s/m_6ad0468ffd748191824f032afe42854c).

`icon.png` preserves the downloaded PNG byte for byte: 1254 × 1254 pixels, 1,375,521 bytes. SHA-256: `dcdb20b290d4f6199c103f66489ef440d44afe0326f899a28d85c737f3ac31b0`.

`icon.iconset` contains standard macOS icon resolutions, each resized directly from `icon.png` with `sips -z HEIGHT WIDTH`. `icon.icns` is built with `iconutil -c icns assets/icon.iconset -o assets/icon.icns`. Only resizing and format conversion were applied; the artwork was not recreated, cropped, or otherwise edited.
